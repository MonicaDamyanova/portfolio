GPU-Accelerated Physics Engine Development

May 2026 - Aug 2026

There is a lot to say about this project... here is my draft.

The get a better understanding on how the original code works I did a lot of profiling using tools like VTune and prof. The original code was written in Fortran and recommeneded to be compiled using the ifx Fortran compiler. This makes it really easy to use VTune.

The output of the profiler showed that a lot of the time spent on the simulation was spent on the overhead to start up multithreading with openMP. Upon investigating the code, much of this openMP implementation was not optimized, so there would be a lot of room to make it better. However, to make it significantly faster, it would need to be completely redesigned from scratch.

...

In the end, the speed up based on one common demo simulation was about 10x. There are many factors which affect this number, Even re running the simulation changes it a bit, so it is very rough. However, it is proof that this prototype would be wrothwhile, especially considering how many further improvements could be done which were out of the scope of this prototype.
